# Курсовая работа по базам данных 5 семестр

## Тема

Разработка информационной системы для записи на приём к врачу в больнице.

## Задание

Требуется создать информационную систему для записи на приём к врачу в поликлинике: реализовать выполнение запросов и создание записи на приём к врачу, разработать систему аутентификации пользователя, программную архитектуру приложения. В поликлинике работают врачи, медицинские регистраторы и администратор. Врачи принимают пациентов в назначенное время, в ходе приёма они делают соответствующие медицинские записи в карту пациента. Для того, чтобы попасть на приём к врачу, необходимо заранее записаться в регистратуре. В регистратуре работают сотрудники, занимающиеся созданием записей на приём к врачу. Главврач является руководителем больницы и имеет возможность выполнять запросы в базу данных.
